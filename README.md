# 한화생명 굿즈 마진 계산기 🎯

정산서 기준 실제 수익을 정확하게 계산하는 굿즈 판매 수익성 분석 도구입니다.

## 📋 주요 기능

- **실시간 계산**: 판매가, 원가, 수수료, 물류비를 입력하면 즉시 순이익 계산
- **다양한 상품 유형**: 유형상품, 무형상품, POP, 스티커 샵 등 지원
- **정산서 기반**: b.stage 정산 명세서 기준으로 정확한 수수료 계산
- **시뮬레이션 저장**: 여러 상품의 수익성 비교 및 기록 관리
- **VAT 포함**: 모든 금액은 부가세 포함 기준

## 🧮 계산 공식

```
순이익 = (판매가 + 배송비) - 원가 - 물류비 - 수수료 - (고정비/판매수)

수수료 = 상품유형% + PG(4%) + 한컴대행(상품유형% × 5%)
```
